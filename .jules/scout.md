**Learning:** `runAutoSim` takes a `WorldState` and simulates entirely through several bashos until a duration or condition is hit. It relies on `simulateEntireBasho`, `publishBanzukeUpdate` and `advanceWithGates`. We can write a suite that mocks out `simulateEntireBasho` lightly (or just use `makeMockWorld` since we found it executes in ~200ms) to ensure `bashoSimulated` respects different durations. **Pattern:** We tested `runAutoSim` using `makeMockWorld()` and simple duration configs (`basho`, `days`, `weeks`, `months`, `years`, `untilEvent`, early exit logic with `duration: { type: "days", count: 0 }`, and explicit `verbosity: "detailed"`) to assert the correct `bashoSimulated` count and `stoppedBy` result.
