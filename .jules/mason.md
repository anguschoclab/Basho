## 2026-10-22 - [Tighten UI Stats Array Type] **Finding:** UI stat sub-functions were using fake `as unknown as Type[]` structural casts just to pass an array because they only checked `.length`. **Learning:** When a consuming function only needs the array length or doesn't use the elements, type the parameter as `unknown[]` instead of forcing a fake structural cast. **Constraint:** Never use dirty array casts to bypass type errors; loosen the argument type instead if only length is evaluated.
