## 2024-10-24 - Tighten selectBloodlineRegistry return type **Finding:** The `selectBloodlineRegistry` selector used `as unknown as Record<string, unknown>` to spread the `BloodlineTrait` properties. **Learning:** Since `BloodlineTrait` already contains `traitId`, we don't need to spread and overwrite it. We can simply use `Object.values(registry.traits)`. **Constraint:** No persistence or serialization logic is affected since this is a UI projection.
