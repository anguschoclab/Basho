# JSA-Alignment Reconciliation: Code vs Docs vs Real Rules

Reconcile Basho's three rule sources — aligning code and documentation to real modern JSA rules wherever feasible (including money tables), keeping explicit user-approved exceptions (ginboshi mechanic, kensho fame-envelope system) documented as deliberate features, filling all documentation gaps, and shipping every change behind a strict test-first schedule.

## Objective

Reconcile the game's rule surface across three sources — **CODE** (`src/engine/**`, `src/constants/engine/**`), **DOCS** (`docs/Basho_Constitution_v1.2_HARMONIZED_NONLOSSY.md`, `docs/user-manual.md`, `docs/design-bible.md`, `docs/superpowers/**`, `docs/audit/**`), and **real modern JSA rules** (post-2023 era) — under a resolved alignment policy:

1. **JSA wins mismatches** — where code/docs/JSA disagree and the real rule is implementable, align code to JSA and docs to code. This resolves the earlier open question: **money tables normalize to real JSA values** (no "2027 revision" inflation).
2. **User-approved exceptions stay, documented honestly**:
   - **Ginboshi** — keep the mechanic; document as the informal fan/media "silver star" term it really is (no official JSA award, no ledger, no mochikyukin).
   - **Kensho envelope mechanics** — keep media-heat bonus envelopes + kinboshi/ginboshi minimum-banner guarantees as the deliberate "fame matters" system; document as game feature. (The ¥70k _value split_ still normalizes to real JSA — that's a value fix, not a mechanic.)
   - Other fiction systems (welfare meter, scandal score, political capital, drama matchmaker, excitement score, era drift, Global Cup, recruitment windows, myoseki market, mandatory retirement, maezumo-filler, jun-yusho label) — keep, labeled game-original.
3. **Doc gaps get filled** — coded features with no doc coverage get new `docs/user-manual.md` sections (Constitution divergence-notice entries where applicable).
4. **Test-first is binding** — every code change lands behind a spec test written and confirmed failing before the implementation edit.
5. **Zero compatibility constraints** — save files/backwards compatibility are not concerns; schema/constant changes are free.

**Deliverables:**

- `docs/audit/rules-divergence-report.md` — the full three-way audit (all 23 domains)
- Code fixes (fix backlog below, test-first)
- Doc reconciliation (drift fixes + new sections + "Known deviations" appendix)
