# Agent Journals

Tracked learnings accumulated by the repo's persona agents (formerly the
`.jules/` directory, which was gitignored local memory — these files are now
committed so the knowledge survives clones and teammates).

Each agent's persona lives in `.claude/agents/<name>.md` and instructs the
agent to read its journal here before working and append new findings.

## Journal format

Each entry is dated and carries **Data** (the datum/field involved),
**Learning** (what was verified empirically), and **Pattern** (the reusable
rule). Entries should record only what cost effort to discover — population
rates, scope caveats, reconciliation quirks — not what the code already
makes obvious.
